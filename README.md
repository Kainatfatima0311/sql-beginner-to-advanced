# 📖 About

This repository documents my complete SQL learning journey from beginner-level concepts to advanced SQL topics and practical database development.

The repository focuses on building a strong SQL foundation through structured notes, executable SQL scripts, hands-on practice, and real-world database engineering concepts using SQLite.

The next stage of this journey will continue with PostgreSQL and production-level database development.
