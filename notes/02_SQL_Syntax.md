## SQL Syntax

### What is SQL Syntax?

- SQL syntax is a set of rules used to write SQL statements correctly.
- If the syntax is incorrect, the query will return an error.

### SQL Statement

- A SQL statement is a command written to perform an action on a database.

Example:

```sql
SELECT * FROM Students;
```

### SQL Keywords

Common SQL keywords include:

- SELECT
- FROM
- WHERE
- INSERT
- UPDATE
- DELETE
- CREATE
- ALTER
- DROP

### Semicolon (;)

- A semicolon marks the end of an SQL statement.
- It is considered a good programming practice to use it.

### Case Sensitivity

- SQL keywords are not case-sensitive.
- Use uppercase keywords for better readability.
- Keep table and column naming consistent.

### SQL Comments

- Use `--` for single-line comments.
- Comments improve code readability and documentation.
