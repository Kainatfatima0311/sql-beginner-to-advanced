## SQL Operators

### Definition

SQL operators are symbols or keywords used to perform operations on values.

### Arithmetic Operators

| Operator | Meaning |
|----------|---------|
| + | Addition |
| - | Subtraction |
| * | Multiplication |
| / | Division |
| % | Modulus |

### Comparison Operators

| Operator | Meaning |
|----------|---------|
| = | Equal |
| > | Greater Than |
| < | Less Than |
| >= | Greater Than or Equal |
| <= | Less Than or Equal |
| <> | Not Equal |
| != | Not Equal |

### Logical Operators

- AND
- OR
- NOT

### Other Operators

- IN
- BETWEEN
- LIKE
- EXISTS
- ANY
- ALL

### Bitwise Operators (SQLite)

- &
- |
- <<
- >>
- ~

### Key Points

- Arithmetic operators perform calculations.
- Comparison operators compare values.
- Logical operators combine conditions.
- IN checks multiple values.
- BETWEEN checks ranges.
- LIKE searches patterns.
